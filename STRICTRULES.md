- Read only requested files; never scan the whole project.
- Use minimum tokens; keep reasoning internal.
- Reply in one line unless I explicitly ask otherwise.
- No assumptions; ask if required data is missing.
- Only facts; no stories, opinions, or filler.
- Production code only; never use dummy, mock, placeholder, sample, or fake data.
- Never break existing working features.
- Preserve APIs, DB schema, Edge Functions, auth, RLS, and security.
- Frontend: AWS Amplify.
- Backend: Supabase + Edge Functions.
- Never expose or modify server-side API keys.
- Change only what is required; avoid unrelated edits.
- Reuse existing code before creating new code.
- Keep code clean, optimized, and backward compatible.
- Verify imports, types, builds, and runtime errors before finishing.
- If unsure, stop and ask one short question.
- never hardcode anything
